# ExperienceHub Project Instructions

## Project goal

Build a premium multi-country dining-experience platform using Astro.

Initial countries:

- Nepal
- New Zealand

Initial Nepal restaurant:

- The Pizza House

Nepal experience:

- Signature Brunch Experience

Nepal packages:

- Family Brunch Package
- Couple Brunch Package
- Friends Brunch Package

New Zealand content:

- A clearly fictional Auckland restaurant
- A premium couple dinner experience
- A couple dinner package

## Content relationship

Country → Restaurant → Experience → Package

The architecture must support adding more countries later without major restructuring.

## Technology direction

Use only when required:

- Astro
- Tailwind CSS
- Minimal JavaScript
- Supabase
- Cloudflare
- OpenRouter
- Google Analytics 4
- Google Tag Manager
- Stripe
- Git and GitHub

## Development rules

- Inspect the current repository before making changes.
- Preserve completed work.
- Do not rebuild the project from scratch.
- Do not add unnecessary files.
- Do not install unnecessary dependencies.
- Do not add React unless genuinely required.
- Use semantic HTML and accessible controls.
- Never commit API keys or `.env` files.
- Put empty variable examples in `.env.example`.
- Run the build after each milestone.
- Complete only the requested milestone.
- Make one Git commit after each successful milestone.
- Stop after the milestone and report what changed.

## Design direction

The website should feel premium, spacious, modern and editorial.

Use:

- Strong typography
- Generous whitespace
- Responsive layouts
- Subtle animations
- Restrained colours
- Clear hierarchy

Avoid:

- Excessive gradients
- Crowded interfaces
- Large animation libraries
- Unnecessary dashboards
- Overengineering
